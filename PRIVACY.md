# Privacy

Akshara processes keystrokes locally and offline inside the application receiving text. The text service does not access the network, log or store typed text, collect analytics or telemetry, run an updater, or launch background processes. Composition text exists only in process memory for the active composition and is discarded on commit, cancellation, focus loss, profile change, or deactivation.

The separate Akshara Help application works offline. Its project-link button opens the user's browser only after an explicit click. Version 1 performs no automatic update checks.
